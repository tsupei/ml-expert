Prior to the landmark 2017 paper *“Attention Is All You Need”* by Vaswani et al., the dominant paradigm in sequence modeling was recurrent architectures (RNN, LSTM, GRU). Recurrence, however, imposes an inherent sequential bottleneck: processing step $t$ strictly demands the hidden state from step $t-1$. This serial dependency prohibits massive GPU parallelization and exacerbates vanishing gradients over long context horizons.

The Transformer eradicated recurrence entirely. By leveraging **Self-Attention**, it establishes direct $O(1)$ signal propagation paths between any two arbitrary tokens in a sequence, translating sequence modeling into highly parallelizable matrix multiplication kernels.

---

## 1. Core Mechanics: Scaled Dot-Product Attention

At its core, self-attention performs a dynamic, query-conditioned retrieval over values: **using the similarity between Queries and Keys as weights to compute a weighted sum of Values**.

The canonical formulation is expressed as:

$$
\text{Attention}(Q, K, V) = \text{softmax}\left(\frac{Q K^T}{\sqrt{d_k}}\right) V
$$

Where:
- $Q \in \mathbb{R}^{N \times d_k}$: Query matrix (features formulating queries)
- $K \in \mathbb{R}^{M \times d_k}$: Key matrix (features matched against queries)
- $V \in \mathbb{R}^{M \times d_v}$: Value matrix (representations to aggregate)
- $d_k$: Projection dimension of keys and queries

## 2. Mathematical Derivation: Why Divide by $\sqrt{d_k}$?

A common question among ML practitioners is: **why does dot-product attention strictly mandate division by $\sqrt{d_k}$?**

This is not a cosmetic heuristic; it is an analytical necessity to prevent **gradient vanishing in the Softmax operator**.

### Derivation Setup

Suppose components of vectors $q = [q_1, \dots, q_{d_k}]$ and $k = [k_1, \dots, k_{d_k}]$ are independent and identically distributed (i.i.d.) random variables with mean 0 and unit variance:

$$
\mathbb{E}[q_i] = 0, \quad \text{Var}(q_i) = 1
$$
$$
\mathbb{E}[k_i] = 0, \quad \text{Var}(k_i) = 1
$$

Their dot product is:

$$
z = q \cdot k = \sum_{i=1}^{d_k} q_i k_i
$$

Let us compute the expectation and variance of $z$:

1. **Expectation**:
   $$
   \mathbb{E}[z] = \sum_{i=1}^{d_k} \mathbb{E}[q_i k_i] = \sum_{i=1}^{d_k} \mathbb{E}[q_i]\mathbb{E}[k_i] = 0
   $$

2. **Variance**:
   Because $q_i$ and $k_i$ are independent:
   $$
   \text{Var}(q_i k_i) = \mathbb{E}[(q_i k_i)^2] - (\mathbb{E}[q_i k_i])^2 = \mathbb{E}[q_i^2]\mathbb{E}[k_i^2] - 0 = (1)(1) = 1
   $$
   Summing across all $d_k$ independent dimensions:
   $$
   \text{Var}(z) = \text{Var}\left(\sum_{i=1}^{d_k} q_i k_i\right) = \sum_{i=1}^{d_k} \text{Var}(q_i k_i) = d_k
   $$

<Callout type="intuition" title="Core Intuition: Dimensionality Drives Variance Explosion">
As embedding dimension $d_k$ grows (e.g. $d_k = 64$ or $128$ in modern LLMs), the variance of the unscaled dot product balloons to $d_k$. Consequently, logit magnitudes easily reach values like $\pm \sqrt{d_k}$ or higher.
</Callout>

### Softmax Saturation and Gradient Collapse

When unscaled logits with high variance are fed into $\text{softmax}(z)$:
- The highest logit receives probability close to $1$.
- All other positions collapse toward $0$.

Recall the Jacobian of Softmax with respect to logits $z_i$:

$$
\frac{\partial \text{softmax}(z)_i}{\partial z_j} = \text{softmax}(z)_i (\delta_{ij} - \text{softmax}(z)_j)
$$

When probability mass concentrates in an extreme one-hot configuration, the derivative terms approach zero asymptotically. Gradients traversing through the attention map virtually vanish!

**The Remedy**:
Scaling the dot product by $1 / \sqrt{d_k}$ standardizes variance:

$$
\text{Var}\left(\frac{q \cdot k}{\sqrt{d_k}}\right) = \frac{1}{d_k} \text{Var}(q \cdot k) = \frac{1}{d_k} \cdot d_k = 1
$$

This guarantees invariant activation statistics regardless of how wide the embedding dimension is chosen, stabilizing gradient dynamics.

## 3. Multi-Head Attention

A single attention head tends to collapse its focus onto a solitary semantic relation. Multi-Head Attention projects Queries, Keys, and Values into $h$ distinct subspaces, enabling the network to **jointly attend to information from different representation subspaces at different positions**:

$$
\text{MultiHead}(Q, K, V) = \text{Concat}(\text{head}_1, \dots, \text{head}_h) W^O
$$
$$
\text{where} \quad \text{head}_i = \text{Attention}(Q W_i^Q, K W_i^K, V W_i^V)
$$

Standard projection dimensions:
- $W_i^Q \in \mathbb{R}^{d_{\text{model}} \times d_k}$
- $W_i^K \in \mathbb{R}^{d_{\text{model}} \times d_k}$
- $W_i^V \in \mathbb{R}^{d_{\text{model}} \times d_v}$
- $W^O \in \mathbb{R}^{h d_v \times d_{\text{model}}}$

Setting $d_k = d_v = d_{\text{model}} / h$ maintains identical total computational complexity and parameter counts compared to single-head attention with full dimensionality.

## 4. Encoder Block & The Pre-LN Paradigm

The original 2017 Transformer adopted **Post-LN**:
$$\text{Output} = \text{LayerNorm}(x + \text{SubLayer}(x))$$

In deep networks ($>20$ layers), Post-LN suffers from unstable gradient propagation through the residual stream, requiring delicate learning rate warmup schedules. Contemporary architectures (e.g. LLaMA, Mistral, GPT series) universally prefer **Pre-LN** (or RMSNorm variants):

$$\text{Output} = x + \text{SubLayer}(\text{LayerNorm}(x))$$

## 5. PyTorch Implementation

A modular, production-ready PyTorch implementation demonstrating tensor reshaping and batched matrix multiplication:

```python
import math
import torch
import torch.nn as nn
import torch.nn.functional as F

class ScaledDotProductAttention(nn.Module):
    def __init__(self, dropout: float = 0.0):
        super().__init__()
        self.dropout = nn.Dropout(dropout)

    def forward(
        self,
        q: torch.Tensor,       # [batch_size, n_heads, seq_len_q, d_k]
        k: torch.Tensor,       # [batch_size, n_heads, seq_len_k, d_k]
        v: torch.Tensor,       # [batch_size, n_heads, seq_len_v, d_v]
        mask: torch.Tensor = None
    ) -> tuple[torch.Tensor, torch.Tensor]:
        d_k = q.size(-1)
        
        # 1. Compute dot-product attention scores: [B, H, S_q, S_k]
        scores = torch.matmul(q, k.transpose(-2, -1)) / math.sqrt(d_k)

        # 2. Apply causal or padding mask
        if mask is not None:
            scores = scores.masked_fill(mask == 0, -1e9)

        # 3. Softmax normalization over key dimension
        attn_weights = F.softmax(scores, dim=-1)
        attn_weights = self.dropout(attn_weights)

        # 4. Context aggregation
        output = torch.matmul(attn_weights, v)
        return output, attn_weights

class MultiHeadAttention(nn.Module):
    def __init__(self, d_model: int, n_heads: int, dropout: float = 0.1):
        super().__init__()
        assert d_model % n_heads == 0, "d_model must be divisible by n_heads"
        
        self.d_model = d_model
        self.n_heads = n_heads
        self.d_k = d_model // n_heads

        # Batched linear projections
        self.w_q = nn.Linear(d_model, d_model, bias=False)
        self.w_k = nn.Linear(d_model, d_model, bias=False)
        self.w_v = nn.Linear(d_model, d_model, bias=False)
        self.w_o = nn.Linear(d_model, d_model, bias=False)

        self.attention = ScaledDotProductAttention(dropout=dropout)

    def forward(self, q, k, v, mask=None):
        batch_size = q.size(0)

        # 1. Project and split heads: [B, S, D] -> [B, H, S, d_k]
        q = self.w_q(q).view(batch_size, -1, self.n_heads, self.d_k).transpose(1, 2)
        k = self.w_k(k).view(batch_size, -1, self.n_heads, self.d_k).transpose(1, 2)
        v = self.w_v(v).view(batch_size, -1, self.n_heads, self.d_k).transpose(1, 2)

        # 2. Scaled dot-product attention
        out, weights = self.attention(q, k, v, mask=mask)

        # 3. Concatenate heads and project output: [B, H, S, d_k] -> [B, S, D]
        out = out.transpose(1, 2).contiguous().view(batch_size, -1, self.d_model)
        return self.w_o(out)
```

## Conclusion

The elegance of the Transformer lies in replacing sequential recurrence with **pure linear algebra and geometric projections**. 

Through the rigorous $\sqrt{d_k}$ scaling, it preserves clean gradient flows across Softmax; through multi-head projections, it constructs orthogonal representational views. In our subsequent deep dive, we will examine the hardware-aware memory hierarchy breakthrough that overcomes the $O(N^2)$ memory wall: **FlashAttention (GPU SRAM Tiling & Online Softmax)**.
